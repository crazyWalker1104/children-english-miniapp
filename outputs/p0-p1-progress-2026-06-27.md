## P0 商用前确认推进

已完成：

- 新增 `data/commercial-readiness.js`。
- 新增 `data/validate-commercial.js`。
- 一键检查脚本已接入商用 readiness 检查。
- 普通检查会显示 pending 项但不阻断 Demo。
- 商用发布前严格检查会阻断 pending 项。

普通检查：

```sh

```

商用严格检查：

```sh
node scripts/check-demo.js --strict-assets --strict-commercial
```

- 真人美语单词 / 短句音频。
- 正式儿歌音频。
- 儿歌歌词版权。
- 最终原创角色素材。

这些事项需要内容、设计、法务或产品负责人实际确认后，才能把 `commercial-readiness.js` 中对应状态改为 `approved`。
