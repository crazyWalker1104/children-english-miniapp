# 儿童英语启蒙微信小程序技术方案

## 1. 技术选型

首版建议使用原生微信小程序开发，原因：

- 页面数量少，交互相对明确
- 音频、录音、本地存储、触摸事件可直接使用微信能力
- 首版重点验证儿童端体验，不需要先引入复杂跨端框架
- 后续如需 H5 / App，可在内容数据和业务规则层做抽离

## 3. 核心模块

### 随机主题池

入口：今日小游戏 / 惊喜任务

规则：

- 根据儿童年龄过滤任务
- 从可用任务池随机抽取
- 避免连续重复上一次任务
- 完成后记录奖励和听过的词汇

### 年龄分层

| 年龄 | 规则 |
| --- | --- |
| 3-4 岁 | 3 个选项，4 块拼图，听点为主 |
| 5 岁 | 4 个选项，6 块拼图，词组与配对 |
| 6 岁 | 4 个选项，9 块拼图，短句与组合 |

Demo 已在家长中心加入年龄切换，设置会保存到本地 `childProfile`，首页和随机主题任务会自动读取当前年龄。

### 学习记录

首版使用 `wx.setStorageSync` 本地保存。

记录内容：

- 今日学习时长
- 完成任务 ID
- 听过的单词
- 儿歌播放次数
- 跟读次数
- 获得奖励

后续可以迁移到微信云开发或自建后端。

## 4. 音频方案

Demo 阶段：

- 用 `utils/audio.js` 统一管理音频占位
- 当前通过 Toast 和文字反馈模拟音频播放

正式阶段：

- 使用 `wx.createInnerAudioContext`
- 音频文件按 `audioKey` 管理
- 单词、短句、儿歌分目录存放
- 播放前停止上一个音频，避免重叠

## 5. 录音方案

首版 P1：

- 使用 `wx.getRecorderManager`
- 录音完成后本地临时回放
- 只记录跟读次数，不做评分

不进入首版：

- AI 发音评分
- 语音识别打分
- 长期保存儿童录音

## 6. 素材方案

Demo 阶段：

- 使用 emoji、色块和 CSS 图形作为占位

正式阶段：

- 角色、名画、贴纸、音频均需要素材表配置
- 第三方 IP 需授权后替换
- 未授权前使用原创角色和原创主题
