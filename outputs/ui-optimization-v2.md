# UI 优化 V2 记录

## 目标

本轮 UI 优化面向 3-6 岁儿童，重点不是增加复杂装饰，而是提升：

- 第一眼吸引力
- 儿童可点击性
- 任务反馈感
- 年龄分层可感知
- 家长端的可信度

## 优化原则

### 1. 主任务更突出

首页保留“今日小游戏 / 惊喜任务”为最大视觉入口。按钮更高、更亮，播放按钮更像可点击的行动点。

### 2. 儿童端更低文字

儿童端优先使用：

- 大标题
- 大图标
- 大按钮
- 简短英文提示
- 即时反馈

长说明只放在家长端和设计文档中。

### 3. 视觉更柔和

调整方向：

- 背景从冷蓝过渡到暖白
- 卡片白色透明感更高
- 阴影更柔和
- 主 CTA 使用珊瑚橙到暖黄渐变
- 年龄标签使用薄荷绿，降低压力感

### 4. 难度提示产品化

首页显示当前年龄和难度模式，例如：

```text
4 岁 · 跟读配对
```

家长中心可以切换 3/4/5/6 岁，切换后随机主题任务自动调整难度。

## Figma 同步说明

当前可直接将以下设计规范搬入 Figma：

- 画板尺寸：微信小程序移动端，建议 375x812
- 主背景：顶部浅蓝 `#EDF8FF` 到暖白 `#FFFDF8`
- 主 CTA：`#FF7F70` 到 `#FFB86C`
- 强调绿：`#72D6B7`
- 强调蓝：`#7CC7F6`
- 标题色：`#243047`
- 辅助文字：`#6C7890`
- 卡片圆角：约 17px
- 大按钮最小高度：92px
- 主要点击区域：不小于 44px

## 后续建议

如果进入 Figma 高保真阶段，建议优先画：

1. 首页
2. 今日小游戏
3. 颜色乐园
4. 家长中心

这四页最能验证视觉调性、任务吸引力和家长可信度。
