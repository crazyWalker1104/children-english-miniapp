# UI 优化 V3 记录 —— Playful Picture Book

## 概览

V3 是本项目的第三次 UI 视觉升级，将设计系统从 V2 的"基础功能型"提升为"趣味绘本风"（Playful Picture Book）。核心目标是让每个页面都有鲜明的视觉记忆点，同时保持 3-6 岁儿童友好的大按钮、大图标、强反馈原则。

V1 → V2 → V3 演进：
- **V1**：建立基础 UI 骨架和页面结构
- **V2**：优化配色、卡片层次、儿童可点击性
- **V3（本轮）**：全新色彩体系、9 个动画关键帧、每页独立视觉主题

## 设计方向

### 视觉主题：Playful Picture Book（趣味绘本风）

**Mood**：温暖、触感、童趣 —— 像翻开一本会动的绘本。

**Tone**：不是"教育软件"，而是"游乐园地图"。

**核心原则**：
1. 每个模块一个专属渐变色，形成视觉区分
2. 正确/完成 = 绿色渐变 + 弹出，错误 = 红色 + 抖动
3. 所有交互有 `scale(0.95)` 按下反馈
4. 装饰元素使用浮动动画，增加生命力
5. 儿童端优先大图标大按钮，文字说明放家长端

| 用途 | 色值 | 说明 |
|------|------|------|

| 文字 | `#2d3436` / `#636e72` / `#b2bec3` | 主/辅/弱三级 |

## 动画系统

在 `styles/tokens.wxss` 中新增 9 个 CSS 关键帧动画：

| 动画名 | 用途 | 触发场景 |
|--------|------|---------|
| `fadeInUp` | 从下方淡入 | 入场动画 |
| `fadeInScale` | 从缩小到正常 | 组件出现、进度点激活 |
| `popBounce` | 弹性弹出 | 贴纸点亮、庆祝 emoji |
| `wiggle` | 水平抖动 | 错误反馈 |
| `floatUpDown` | 上下浮动 | 装饰星星、挥手 emoji |
| `starPop` | 旋转弹出 | 贴纸槽位点亮 |
| `progressGlow` | 光晕脉冲 | 当前步骤指示器 |
| `gentlePulse` | 缩放呼吸 | 完成按钮 |
| `slideInRight` | 从右侧滑入 | 备用入场 |
| `shimmer` | 光泽扫过 | 备用高亮 |

## V2 → V3 关键变化

| 维度 | V2 | V3 |
|------|----|----|
| 色彩 | 单一珊瑚橙 + 薄荷绿 | 5 色模块专属渐变 |
| 动画 | 无 | 9 个关键帧动画 |
| 首页 Hero | 简单吉祥物卡片 | 暖金渐变 + 浮动装饰 + 挥手 |
| 模块网格 | 统一白色卡片 | 四色独立渐变 |
| 贴纸进度 | 文字 "★ ★ ★" | 三段式圆形槽位 + 连接线 + 弹出动画 |
| 步骤流程 | 文字 pill 标签 | 圆形指示器 + 连接线 + 三态动效 |
| 拼图板 | 简单深蓝背景 | 星空夜景 + 光晕 + 浮动星星 |
| 家长统计 | 垂直列表 | 3 列网格 + 大数字 |
