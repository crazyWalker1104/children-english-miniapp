## 2. MVP 开发目标

做出一个可在微信开发者工具中完整体验的儿童英语启蒙小程序 MVP。

核心闭环：

```text
打开首页
→ 点击今日小游戏
→ 随机出现一个主题任务
→ 儿童完成点击 / 跟读 / 拼图 / 儿歌互动
→ 获得鼓励反馈和贴纸
→ 家长中心看到学习记录
```

## 4. P0 功能验收标准

### 首页

- 能显示儿童年龄与难度模式
- 能点击进入 6 个模块
- 能展示今日贴纸进度
- 完成任务后回到首页，贴纸状态更新

### 今日小游戏

- 点击进入后随机抽取任务
- 连续两次不出现同一个任务
- 根据年龄调整选项数量
- 正确选择显示 `Great job!`
- 错误选择显示 `Try again!`
- 完成后写入学习记录

### 颜色乐园

- 展示 6 个基础颜色
- 点击播放/模拟英文发音
- 正确颜色可获得奖励
- 听过的颜色进入家长记录

### 儿歌时间

- 展示 3 首儿歌
- 点击可播放/模拟播放
- 播放次数写入学习记录
- 完成后获得贴纸

### 小小艺术家

- 展示儿童化《星月夜》占位画
- 支持 4 块拼图点击完成
- 完成后显示 `Beautiful!`
- 记录艺术贴纸

### 家长中心

- 可切换 3/4/5/6 岁
- 年龄设置本地保存
- 显示任务数、词汇数、儿歌次数、跟读次数、贴纸数
- 可清空本地学习记录

## 7. 技术风险

### 录音权限

风险：

- 微信录音需要用户授权
- 儿童产品涉及隐私敏感

建议：

- P1 再做录音
- 首版只做“播放原音 + 点击鼓励”
- 如上线录音，需加入家长同意说明

### 音频资源体积

风险：

- 儿歌音频可能增大小程序包体

建议：

- 单词音频可随包
- 儿歌音频建议走 CDN
- 首版先用压缩音频

### IP 授权

风险：

- 未授权角色不可商用

建议：

- 使用原创角色
- 把第三方 IP 作为商务合作预留方向
