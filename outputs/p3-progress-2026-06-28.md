### 2. 请求封装增强

为 `utils/request.js` 增加生产级网络请求能力。

**新增功能**：

- 统一超时配置：默认 15 秒，可按请求通过 `options.timeout` 覆盖
- 自动 token 注入：从本地存储读取 `auth_token`，自动添加 `Authorization: Bearer` 头
- 401 自动清除过期 token
- 统一错误码映射：覆盖 400/401/403/404/500/502/503/504 及网络失败，返回用户可读提示
- 统一错误提示：默认 `wx.showToast` 提示，可通过 `options.showError: false` 关闭
- 便捷方法：`get()` / `post()` / `put()` / `del()`

**API 兼容性**：

- 原 `request(options)` 签名完全保留，现有调用无需修改
- 新增便捷方法为可选使用

**涉及文件**：

- 修改：`utils/request.js`

### 3. 内容导入脚本测试覆盖

为 `data/import-words.js` 和 `data/import-songs.js` 创建 29 项单元测试。

**测试覆盖**：

| 模块 | 测试项 | 数量 |
| --- | --- | ---: |
| parseCsv | 正常解析/带引号/双引号转义/BOM 移除/空行过滤/空 CSV 报错 | 7 |
| normalizeId | 小写化/空字符串/前后连字符 | 3 |
| normalizeAge | 有效年龄/小于 3/大于 6/非整数 | 4 |
| normalizeWord | 完整字段/phrase 回退/pending 跳过/缺字段报错 | 4 |
| normalizeSong | 完整字段/audioKey 回退/缺歌词报错/pending 跳过 | 4 |
| buildLine | 缺 text/缺 action 返回 null | 1 |
| mergeWords | 新增追加/同 id 更新/重复 id 报错 | 3 |
| mergeSongs | 新增追加/同 id 更新/重复 id 报错 | 3 |

**运行方式**：

```sh
node scripts/test-import.js
```

**涉及文件**：

- 新增：`scripts/test-import.js`
- 修改：`data/import-words.js`（导出 `normalizeId`/`normalizeAge`/`normalizeWord`/`mergeWords`）
